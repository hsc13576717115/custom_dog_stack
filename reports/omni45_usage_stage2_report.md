# CustomDog Omni45 Usage Stage-2 试验报告

## 结论

第二阶段没有产生可冻结候选。第一阶段冻结模型 `model_4840` 在扩大 command clip 后，
可以稳定完成 `0.75/1.0/1.25/1.5 m/s` 直行，但高速 `vx+wz` 会产生明显 body-y
串扰。三组独立续训均未将该误差降到 `0.07 m/s` 门槛，因此第一阶段候选保持不变，
Stage-2 checkpoint 不进入 `deploy/candidates/`。

## 基线能力

只放宽第一阶段 ONNX 的命令裁剪、不修改策略时：

| 命令 `(vx, vy, wz)` | 实际速度 | 结论 |
|---|---|---|
| `(1.0, 0, 0)` | `(1.062, -0.029, 0.044)` | 直行通过 |
| `(1.25, 0, 0)` | `(1.278, -0.024, 0.066)` | 直行通过 |
| `(1.5, 0, 0)` | `(1.502, -0.045, 0.084)` | 直行通过 |
| `(1.0, 0, +0.2)` | `(1.016, -0.110, 0.309)` | `vy/wz` 未通过 |
| `(1.25, 0, +0.25)` | `(1.217, -0.141, 0.384)` | `vy/wz` 未通过 |
| `(1.5, 0, +0.3)` | `(1.423, -0.197, 0.445)` | `vy/wz/tilt` 未通过 |
| `(1.5, 0, -0.3)` | `(1.508, +0.201, -0.297)` | `vy` 未通过 |

这说明第二阶段不是高速步态或稳定性问题，而是高速转向时的横向速度闭环问题。

## 训练试验

所有试验都从冻结的 `model_4840.pt` 重新开始，optimizer 不恢复，保持 45 维 policy
observation、12 维 action、CPU PhysX 和 CUDA PPO learner。

| run | iterations | 修改 | 结果 |
|---|---:|---|---|
| `2026-08-10_19-22-59_omni45_usage_stage2_from4840_100` | 100 | 全范围采样，inactive-axis L2 `-2` | 10/16，后期退化 |
| `2026-08-10_19-34-09_omni45_usage_stage2_targeted_from4840_60` | 60 | 45% 高速采样，inactive-axis L2 `-6` | 9/16，未改善 `vy` |
| `2026-08-10_19-45-16_omni45_usage_stage2_turn_from4840_200` | 200 | 高速只用于 `vx`/`vx+wz`，专用漂移 L2 `-12` | 无 checkpoint 通过关键网格 |

最后一轮每 20 iterations 的关键网格结果：

| checkpoint | 通过数 | 最大 `vy` 误差 | 最大 `wz` 误差 | 最大倾角 |
|---|---:|---:|---:|---:|
| baseline `4840` | 5/9 | 0.200 | 0.151 | 9.97 deg |
| `4860` | 5/9 | 0.223 | 0.137 | 10.38 deg |
| `4880` | 5/9 | 0.213 | 0.119 | 10.15 deg |
| `4960` | 5/9 | 0.233 | 0.095 | 10.17 deg |
| `4980` | 5/9 | 0.215 | 0.094 | 9.86 deg |
| `5000` | 5/9 | 0.212 | 0.105 | 9.60 deg |

`wz` 可以通过更强奖励改善，但 `vy` 没有随训练持续下降。继续增加 iterations 或 reward
权重没有证据支持，反而会损害低速能力和姿态。

## 根因边界

当前 45 维 actor observation 为：角速度 3、重力投影 3、速度命令 3、关节位置 12、
关节速度 12、上一动作 12。actor 看不到真实 `vx/vy`；只有 critic 在训练时看到
base linear velocity。低速下策略可以靠命令到动作的前馈映射工作，但高速转向的侧滑随
接触和模型误差变化，actor 没有直接反馈量去闭环修正。以上试验表明单纯调整 reward 和
采样分布不足以解决该限制。

## 后续验证

上述 47 维最小修改已经执行。普通微调和冻结旧 actor 的输入适配器微调都未通过固定
网格，结论与原始数据见
[`omni47_velocity_feedback_ablation.md`](omni47_velocity_feedback_ablation.md)。第一阶段
45 维候选继续保持冻结；没有 47 维 checkpoint 进入部署目录。
